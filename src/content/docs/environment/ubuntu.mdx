Ubuntu에서 ReDroid를 설치하고 카카오톡을 준비합니다.

<Callout type="warning" title="주의">
  ReDroid의 네트워크 ADB 접속에는 인증이 없으므로, 외부에 공개된 서버에서는 방화벽 등으로 접속을 제한하세요.
</Callout>

## ReDroid 설치

1. Ubuntu 터미널에서 `arisa_control`을 내려받습니다.

```sh
wget https://github.com/huni-ee/arisa2/releases/latest/download/arisa_control
chmod +x arisa_control
```

2. `arisa_control`을 이용해 ReDroid를 설치합니다.

```sh
./arisa_control install_redroid
```

3. ADB를 설치하고 ReDroid에 접속합니다. Ubuntu에서 직접 접속한다면 `봇IP`에 `127.0.0.1`을, 다른 PC에서 접속한다면 Ubuntu의 IP 주소를 입력합니다.

```sh
sudo apt update
sudo apt install adb
adb connect 봇IP:5555
```

4. [scrcpy 릴리스 페이지](https://github.com/Genymobile/scrcpy/releases)에서 Linux용 파일을 내려받아 압축을 풉니다. 압축을 푼 폴더에서 터미널을 열고 실행합니다.

```sh
./scrcpy -s 봇IP:5555
```

<Callout type="info" title="안내">
  scrcpy 화면을 보려면 실행하는 PC에 그래픽 데스크톱 환경이 필요합니다. 화면이 없는 Ubuntu Server를 사용한다면 데스크톱이 있는 다른 PC에서 ADB와 scrcpy로 Ubuntu IP에 접속하세요.
</Callout>

5. ReDroid에 카카오톡을 설치합니다. split APK 파일을 별도 폴더에 준비한 뒤, `/경로/카카오톡`을 실제 APK 폴더 경로로 바꿔 실행합니다.

```sh
adb -s 봇IP:5555 install-multiple /경로/카카오톡/*.apk
```

## Arisa 설치 및 실행

카카오톡 설치가 끝나면 **Ubuntu 터미널**에서 ReDroid의 ADB 연결을 확인합니다. 다른 PC에서 scrcpy를 사용했다면 Ubuntu에서도 다음 명령을 실행하세요.

```sh
adb connect 127.0.0.1:5555
adb devices
```

목록에 `127.0.0.1:5555`가 `device` 상태로 표시되는지 확인합니다. `arisa_control`을 내려받은 폴더에서 Arisa를 설치하고 실행합니다.

```sh
./arisa_control install
./arisa_control start
```

실행 상태는 다음 명령으로 확인할 수 있습니다.

```sh
./arisa_control status
```

설정을 변경하려면 다음 명령을 사용합니다.

```sh
./arisa_control config
```

Arisa가 실행되면 [사용 예제](/docs/examples)를 따라 Nazu로 봇을 만들어 보세요. 같은 Ubuntu에서 연결할 때는 `127.0.0.1:3000`을 사용합니다.
