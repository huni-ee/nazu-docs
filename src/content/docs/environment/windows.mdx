Windows에서 Hyper-V로 Ubuntu 가상 머신을 만들고, 그 안에 ReDroid를 설치합니다.

## 시작하기 전에

<Callout type="warning" title="주의">
  이 가이드에서 사용하는 ReDroid의 네트워크 ADB 접속에는 인증이 없으므로, 공인 IP가 외부에 노출된 서버에 설치할 때는 반드시 별도의 접근 제어를 적용해야 합니다. 외부 스위치를 사용하면 같은 네트워크의 다른 기기에서도 접근할 수 있으므로 방화벽 등으로 접속을 제한하세요.
</Callout>

ReDroid는 루트 권한을 사용할 수 있는 Android 환경입니다. Arisa는 ReDroid 안에서 카카오톡과 함께 실행되고, 봇 코드는 Ubuntu나 Windows에서 실행해 gRPC로 연결합니다.

## 1. Hyper-V 설치

Hyper-V를 사용할 수 있는 Windows PC와 가상화가 활성화된 환경이 필요합니다. Windows 10·11 Home에는 Hyper-V가 기본 지원되지 않습니다. 자세한 내용은 [Microsoft의 Hyper-V 설치 안내](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/get-started/install-hyper-v)를 확인하세요.

1. **Win + R**을 누르고 `appwiz.cpl`을 입력합니다.
2. **Windows 기능 켜기/끄기**를 선택합니다.

{/* 이미지: 프로그램 및 기능에서 Windows 기능 켜기/끄기 선택 */}

3. **Hyper-V**를 선택하고 **확인**을 누릅니다.

{/* 이미지: Windows 기능에서 Hyper-V 선택 */}

4. 설치가 끝나면 Windows를 다시 시작합니다.

## 2. VM 생성

1. **Hyper-V 관리자**를 실행합니다.

{/* 이미지: 시작 메뉴의 Hyper-V 관리자 검색 */}

2. 먼저 가상 스위치 관리자에서 **외부** 스위치를 만듭니다. 현재 인터넷에 연결된 네트워크 어댑터를 선택하고, **관리 운영 체제에서 이 네트워크 어댑터를 공유하도록 허용**을 선택합니다. 적용할 때 네트워크가 잠시 끊길 수 있습니다.

{/* 이미지: 외부 가상 스위치 설정 */}

3. Hyper-V 관리자에서 **새로 만들기 → 가상 컴퓨터**를 선택합니다.

{/* 이미지: Hyper-V 관리자에서 새 가상 컴퓨터 만들기 */}

4. 다음과 같이 가상 컴퓨터를 설정하고 **마침**을 누릅니다.

| 항목 | 설정 |
| --- | --- |
| 이름 | `redroid` |
| 세대 | 2세대 |
| 메모리 | 최소 4GB, 8GB 권장 |
| 네트워크 | 앞에서 만든 외부 가상 스위치 |
| 가상 하드 디스크 | 기본 설정 |
| 설치 옵션 | 부팅 가능한 CD/DVD-ROM에서 운영 체제 설치를 선택하고 Ubuntu Server ISO 지정 |

[Ubuntu 미러](https://mirror.kakao.com/ubuntu-releases/26.04.1/)에서 **Ubuntu Server 26.04.1 LTS**의 `ubuntu-26.04.1-live-server-amd64.iso` 파일을 받습니다.

5. 생성한 가상 머신의 **설정 → 보안**에서 **보안 부팅 사용**을 해제하고 **적용**을 누른 뒤 가상 머신을 시작합니다.

## 3. Ubuntu 설치

1. 부팅 메뉴에서 **Try or Install Ubuntu**를 선택합니다.
2. 언어는 **English**를 선택합니다.
3. 설치 프로그램 업데이트 화면이 나오면 **Continue without updating**을 선택합니다.
4. 키보드 설정은 변경하지 않고 진행합니다.
5. 설치 유형은 기본 **Ubuntu Server**를 선택합니다.
6. 네트워크는 DHCP로 설정합니다. 화면에 표시되는 IP 주소를 기억해 둡니다.
7. Proxy는 비워 두고 진행합니다.
8. Mirror는 `http://mirror.kakao.com/ubuntu/`로 설정합니다.
9. 저장소 설정에서 설치 대상이 **가상 머신의 가상 디스크**인지 확인하고 **Use an entire disk**를 선택합니다.
10. 파티션 요약을 확인하고 **Continue**를 선택합니다.
11. 이름, 호스트 이름, 사용자 이름과 비밀번호를 설정합니다.
12. Ubuntu Pro 설정 화면이 나오면 **Skip for now**를 선택합니다.
13. **Install OpenSSH server**를 선택합니다.
14. 추가 패키지는 선택하지 않고 진행합니다.
15. 설치가 시작됩니다.

{/* 이미지: Ubuntu 설치 진행 화면 */}

16. **Reboot Now**가 나타나면 선택합니다. 설치 미디어를 제거하라는 메세지가 나오면 Hyper-V 연결 창의 **미디어 → DVD 꺼내기**를 선택하고 Enter를 누릅니다.
17. 부팅이 완료되면 연결 창을 닫습니다. 연결 창을 닫아도 가상 머신은 계속 실행됩니다.
18. Windows 터미널에서 SSH로 Ubuntu에 접속합니다. `사용자이름`과 `Ubuntu_IP`는 설치할 때 설정하고 확인한 값으로 바꿉니다.

```powershell
ssh 사용자이름@Ubuntu_IP
```

{/* 이미지: Windows 터미널에서 Ubuntu SSH 접속 */}

<Callout type="idea" title="팁">
  IP 주소를 기억하지 못한다면 가상 머신에 로그인해 환영 메세지 또는 `ip -4 addr` 명령으로 확인합니다. DHCP로 할당된 주소는 바뀔 수 있습니다.
</Callout>

## 4. ReDroid 설치

1. SSH로 연결한 Ubuntu 터미널에서 `arisa_control`을 내려받습니다.

```sh
wget https://github.com/huni-ee/arisa2/releases/latest/download/arisa_control
chmod +x arisa_control
```

2. `arisa_control`을 이용해 ReDroid를 설치합니다.

```sh
./arisa_control install_redroid
```

3. Windows에서 다른 터미널 창을 열고 [scrcpy](https://github.com/Genymobile/scrcpy/releases)를 내려받아 압축을 푼 폴더로 이동합니다. `봇IP`는 Ubuntu 가상 머신의 IP 주소로 바꿉니다.

```powershell
.\adb.exe connect 봇IP:5555
.\scrcpy.exe -s 봇IP:5555
```

{/* 이미지: ADB와 scrcpy로 ReDroid에 접속한 화면 */}

4. ReDroid에 카카오톡을 설치합니다. split APK 파일을 별도 폴더에 준비한 뒤, scrcpy 폴더의 PowerShell에서 `C:\경로\카카오톡`을 실제 APK 폴더 경로로 바꿔 실행합니다.

```powershell
$apkFiles = (Get-ChildItem -Path 'C:\경로\카카오톡\*.apk' -File).FullName
.\adb.exe -s 봇IP:5555 install-multiple $apkFiles
```

## 5. Arisa 설치 및 실행

Arisa는 Ubuntu 터미널 또는 Windows PowerShell에서 설치할 수 있습니다. 두 방법 중 하나를 선택하세요.

### Ubuntu 터미널에서 설치

카카오톡 설치가 끝나면 **SSH로 연결한 Ubuntu 터미널**로 돌아가 Arisa를 설치합니다. Windows에서 사용한 ADB와 별도로 Ubuntu에서도 ADB를 설치하고 ReDroid에 연결합니다.

```sh
sudo apt update
sudo apt install adb
adb connect 127.0.0.1:5555
adb devices
```

목록에 `127.0.0.1:5555`가 `device` 상태로 표시되는지 확인합니다. `arisa_control`을 내려받은 폴더에서 Arisa를 설치하고 실행합니다.

```sh
./arisa_control install
./arisa_control start
```

실행 상태는 다음 명령으로 확인할 수 있습니다.

```sh
./arisa_control status
```

설정을 변경하려면 다음 명령을 사용합니다.

```sh
./arisa_control config
```

### Windows PowerShell에서 설치

Windows의 **scrcpy 압축을 푼 폴더**에서 PowerShell을 열고 아래 명령을 실행합니다. `봇IP`는 Ubuntu 가상 머신의 IP 주소로 바꿉니다. 첫 번째 명령은 현재 PowerShell에서 `adb`를 찾을 수 있도록 scrcpy 폴더를 PATH에 추가합니다.

```powershell
$env:Path = "$PWD;$env:Path"
.\adb.exe connect 봇IP:5555
.\adb.exe devices
```

목록에 `봇IP:5555`가 `device` 상태로 표시되면 같은 PowerShell에서 Windows용 스크립트를 내려받아 설치하고 실행합니다.

```powershell
Invoke-WebRequest -Uri 'https://github.com/huni-ee/arisa2/releases/latest/download/arisa_control.ps1' -OutFile 'arisa_control.ps1'
.\arisa_control.ps1 install
.\arisa_control.ps1 start
.\arisa_control.ps1 status
```

설정을 변경하려면 다음 명령을 사용합니다.

```powershell
.\arisa_control.ps1 config
```

Arisa가 실행되면 [사용 예제](/docs/examples)를 따라 Nazu로 봇을 만들어 보세요. Windows에서 연결할 때는 Ubuntu 가상 머신의 IP 주소와 포트 `3000`을 사용합니다.
