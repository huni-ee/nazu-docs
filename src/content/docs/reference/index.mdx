---
title: 레퍼런스
description: Nazu 소스 주석으로 만든 API 레퍼런스입니다.
---

레퍼런스는 Nazu 소스의 주석을 [TypeDoc](https://typedoc.org)으로 읽어 만듭니다. 모듈은 소스의 `src` 폴더 구조를 따릅니다. 기본 사용 방법은 [사용 예제](/docs/examples)를 참고하세요.

| 모듈 | 내용 |
| --- | --- |
| [client](/docs/reference/client) | `ArisaClient`, 생성자 옵션, 이벤트 리스너 타입 |
| [channel](/docs/reference/channel) | `Channel`, `NormalChannel`, `OpenChannel`, 채팅방·미디어 전송·채팅 수 타입 |
| [chat](/docs/reference/chat) | `MessageChat`과 메세지 종류, `FeedChat`과 피드 종류, 첨부 데이터 타입 |
| [user](/docs/reference/user) | `User`와 유저 종류, 이벤트 유저 객체, 유저 원본 데이터 타입 |
| [kakao-link](/docs/reference/kakao-link) | `KakaoLink`, 전송 옵션, 카카오링크 오류 |
| [decorators](/docs/reference/decorators) | `isReply`, `hasParam`, `isAdmin`, `isNotBanned`, 관리자·밴 함수 |
